WHY NARANI

Not just code — shared intent

The "why, what, and how" flows between your team and your tools — not only the output the agent produced.

4-layer concept graph

Concept → domain → component → implementation. Each node carries why/what/how/in/out, turning code intent into a map.

Team agent feed

What a teammate's agent did is shared over git. Each entry is one file, so there are no merge conflicts.

Unified marketplace

Skills, MCPs and plugins for Claude, Codex and Gemini in one place — install straight from a URL or GitHub repo.

Code space

A workspace with a built-in Monaco editor and terminal — syntax highlighting and autocomplete to read and fix in place.

Built-in code index

An always-on index that pins down symbols, definitions and references — so agents don't read whole files, saving tokens.

Official protocols

No fragile output parsing — it connects through Claude Agent SDK, Codex app-server and Gemini ACP.
